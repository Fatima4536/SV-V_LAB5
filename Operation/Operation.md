# SV-V_LAB5
| op_id | op_name | description |
|---|---|---|
| OP01 | Perform Sensor Self-Check | Checks whether all essential sensors are working correctly. |
| OP02 | Check Environmental-Control Devices | Checks whether environmental-control devices are functioning properly. |
| OP03 | Record Artifact Identification | Records the identification information of the artifact. |
| OP04 | Load Environmental Limits | Loads the required environmental limits for the artifact. |
| OP05 | Monitor Artifact Conditions | Continuously monitors the artifact and chamber conditions. |
| OP06 | Check Chamber Door Status | Checks whether the chamber door is open or closed. |
| OP07 | Compare Temperature with Allowed Range | Compares the actual temperature with the permitted temperature range. |
| OP08 | Compare Humidity with Allowed Range | Compares the actual humidity with the permitted humidity range. |
| OP09 | Correct Temperature | Attempts to restore the temperature to the required range. |
| OP10 | Correct Humidity | Attempts to restore the humidity to the required range. |
| OP11 | Verify Environmental Recovery | Verifies through sensor readings that the environmental condition has returned to the permitted range. |
| OP12 | Generate Operator Alert | Generates an alert for the museum operator when protection is required. |
| OP13 | Detect Significant Vibration | Detects significant vibration using the vibration sensor. |
| OP14 | Suspend Risk-Increasing Activities | Temporarily suspends activities that could increase risk to the artifact. |
| OP15 | Verify Vibration Stabilization | Verifies that vibration remains below the permitted threshold for the required period. |
| OP16 | Suspend Normal Conservation | Immediately suspends normal conservation activities when the chamber door is opened. |
| OP17 | Verify Sensor Status | Checks sensor status before returning to normal operation. |
| OP18 | Reduce Light Exposure | Reduces light exposure while protecting the artifact. |
| OP19 | Activate Additional Environmental Controls | Activates additional controls to protect the artifact. |
| OP20 | Switch to Emergency Power | Switches to an emergency power source when available after power loss. |
| OP21 | Record Power-Loss Incident | Records the power-loss incident when emergency power is unavailable. |
| OP22 | Verify Chamber Safe Condition | Verifies that the chamber is safe and no protection response is active. |
| OP23 | Authorize Artifact Removal | Allows artifact removal only when the chamber is confirmed safe. |
